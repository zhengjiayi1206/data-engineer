# 清洗策略

保留不可变原始层和处理规则版本，所有排除记录可追溯。销售报表将正向商品、退货、运费、折扣和坏账分别统计，再依据业务确认的口径合成净额；没有客户 ID 的交易仍可能是有效销售，不因匿名而删除。对于客户分群，仅选择能识别客户的交易，按独立发票计算频次；本题 RFM 的金额使用正向商品销售额，不能称为退货后的净消费。商品推荐只使用能关联到用户的正向商品行为，排除费用和取消，将退货作为独立的负向或待解释信号。

数量为负、价格为负或极大值并不自动等于错误，可能是退货、调整或冲销，应先查看同一客户、商品与时间附近的记录。完整重复行也未必是系统重复，需要业务主键确认。按编码形式排除非商品是一种有损启发式：实际数据里的 DCGS 等字母开头编码包含商品，应该补充商品主数据或维护例外清单，不能仅凭正则认定。去重、过滤零价、异常值截断、删除匿名客户和将退货关联到原单都会损失信息或引入假设，应记录影响数量、版本和原因；无法确认的记录进入待核实集合，而不是静默丢弃。
